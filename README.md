## Задача 1
1) Создал виртуальную машину Ubuntu 26.04 на своём Гипервизоре Esxi
2) Начал ознакомление с Yandex Cloud CLI на официальном сайте Yandex Cloud
3) Воспользовался руководством по автоматической установке и настройке Yandex Cloud CLI через запуск готового Bash скрипта
4) После установки убедился что работает автодополнение команд CLI в консоли
5) Для работы с Yandex Cloud я не буду использовать свою личную учетную запись с полным доступом, поэтому я создал Сервесную учетную запись
6) Выдал для своей сервисной учетной записи, полные права на управление виртуальными машинами compute.admin
7) Создал авторизованный ключ доступа и сохранил файл в формате authorized_key.json
8) Передал файл authorized_key.json на сервер
9) Создал профиль в CLI через команду `yc config profile create admin-vm`
10) Проверил что новый профиль активен `yc config profile list`
11) Привязал авторизованный ключ к профилю `yc config set service-account-key authorized_key.json`
12) Указал ID своего облака и ID папки `yc config set cloud-id <MY_CLOUD_ID>` и `yc config set folder-id <yc config set folder-id>`
13) Проверил что данные применились `yc config list`
14) Проверил что сервисный аккаунт имеет доступ до инстанса виртуальных машин `yc compute instance list` и видит мою ранее созданую ВМ
15) Увидел что все настройки нового созданного профиля храняться локально в домашней директории пользователя в системе `~/.config/yandex-cloud/config.yaml`
